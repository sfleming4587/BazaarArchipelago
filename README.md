# BazaarArchipelago

Log reader for The Bazaar on Steam to allow checks for Archipelago. An Archipelago world and client for The Bazaar. The client only reads the game's own `Player.log`:
no mods, no memory reading, no server calls, no automated input (see Tempo's modding policy).

## Layout

- `bazaar/` - the world (becomes `bazaar.apworld`). Player-facing docs are in `bazaar/docs/`.
- `bazaar/logparser.py` - Player.log parsing, no Archipelago imports.
- `bazaar/client.py` - CommonClient-based client ("The Bazaar Client" in the Launcher).
- `bazaar/data/bazaar_data.json` - card and pack data, generated by `tools/extract_data.py`.
- `Archipelago/` (not in git) - Archipelago 0.6.7 source checkout for development. `worlds/bazaar` is a junction to `bazaar/`.
- `.venv/` (not in git) - Python 3.13 (Archipelago doesn't support 3.14).

## Dev setup

```sh
git clone --depth 1 --branch 0.6.7 https://github.com/ArchipelagoMW/Archipelago.git
py -3.13 -m venv .venv   # or: uv venv --python 3.13 .venv
.venv/Scripts/python -m pip install -r Archipelago/requirements.txt pytest pytest-subtests
# PowerShell: New-Item -ItemType Junction -Path Archipelago/worlds/bazaar -Target bazaar
```

## Common tasks

```sh
# refresh card data after a game patch (launch the game once first)
python tools/extract_data.py

# run tests
cd Archipelago && ../.venv/Scripts/python.exe -m pytest worlds/bazaar

# build bazaar.apworld (lands in Archipelago/build/apworlds/)
cd Archipelago && ../.venv/Scripts/python.exe Launcher.py "Build APWorlds" -- "The Bazaar"
```

Bump `world_version` in `bazaar/archipelago.json` for every release. Never renumber item or location ids:
the extractor keeps existing `ap_id`s and appends new cards, and heroes are append-only.
